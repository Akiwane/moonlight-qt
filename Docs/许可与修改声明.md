# Moonlight Qt for JAHDesk

This distribution is a modified version of Moonlight Qt 6.2.0. Akiwane made the JAHDesk changes on **2026-11-23**. The changes add in-window streaming controls on macOS and Windows, an option to keep the local cursor visible in absolute mouse mode, and the build and packaging steps for these releases.

Moonlight Qt and the JAHDesk modifications are available under the GNU General Public License, version 3 or any later version (`GPL-3.0-or-later`). The original Moonlight copyright and license notices apply. The full GPL text is provided with this distribution. [Upstream Moonlight Qt 6.2.0](https://github.com/moonlight-stream/moonlight-qt/tree/v6.2.0)

The matching `Moonlight-JAHDesk-source.tar.gz` on the same release page contains the Moonlight Qt source, its recursive submodules, and the release build scripts. `Moonlight-JAHDesk-release.json` identifies the source commit and SHA-256 hashes. The source archive is available at no charge. [JAHDesk fork releases](https://github.com/Akiwane/moonlight-qt/releases)

The packages also contain third-party libraries with their own license terms. The macOS build uses Qt 6.11.2 and the Windows x64 build uses Qt 6.12.0. The build uses the upstream Moonlight dependency bundles at v19, including FFmpeg and SDL. [Qt 6.11.2 source](https://code.qt.io/cgit/qt/qt5.git/tree/?h=v6.11.2) · [Qt 6.12.0 source](https://code.qt.io/cgit/qt/qt5.git/tree/?h=v6.12.0) · [Moonlight v19 dependency builds](https://github.com/moonlight-stream/moonlight-qt-deps/releases/tag/v19)
